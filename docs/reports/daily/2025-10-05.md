## 🔍 Teknik Detaylar

### Repository Pattern Improvements

**buildFilterConditionsWithOffset() Fonksiyonu:**
```go
// Öncesi - Search'te parameter conflict
func buildFilterConditions(filters) ([]string, []interface{}) {
    paramCount := 1  // $1'den başlıyor
}

// Sonrası - Flexible parameter offset
func buildFilterConditionsWithOffset(filters, startParam int) {
    paramCount := startParam  // İstenen yerden başlıyor
}
```

**Kullanımı:**
```go
// List metodunda $1'den başla
conditions, args := r.buildFilterConditions(filters)

// Search metodunda $2'den başla ($1 search pattern için)
conditions, args := r.buildFilterConditionsWithOffset(filters, 2)
```

### NULL Value Handling Pattern

```go
// List/Search metodlarında
var transactionFeePercentage, basePrice, rating sql.NullFloat64
var icon, currency sql.NullString

err := rows.Scan(
    &basePrice, &currency,
    &transactionFeePercentage,
    &icon, &rating,
    // ...
)

// NULL check
if basePrice.Valid {
    tool.BasePrice = basePrice.Float64
}
if currency.Valid {
    tool.Currency = currency.String
}
```
